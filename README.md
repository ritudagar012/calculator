# Java Calculator

A simple command-line calculator built in Java. It takes two numbers and an operator as input and returns the result.

## Features
- Addition, Subtraction, Multiplication, Division
- Handles division by zero
- Handles invalid operator input

## How to Run
1. Compile: `javac Calculator.java`
2. Run: `java Calculator`
3. Enter first number, operator (+, -, *, /), and second number when prompted
